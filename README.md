# Sri Annai Crackers

Files:
- index.html — main website
- styles.css — website design
- products.js — complete product catalogue
- app.js — cart, delivery calculation and WhatsApp ordering

## GitHub Pages
1. Upload all four files to the root of your GitHub repository.
2. Make sure the main file is named exactly `index.html` (lowercase).
3. Go to Settings → Pages.
4. Under Build and deployment choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
5. Save and open the URL GitHub shows.

## Important
The site is designed to work from GitHub Pages without a backend.
WhatsApp ordering uses +91 73050 89610.

Delivery rates in app.js are sample rates and should be replaced with the actual courier rates before taking live orders.
